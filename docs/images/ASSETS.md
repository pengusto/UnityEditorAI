# Documentation image provenance

## Penguin banners

- `unityeditorai-banner-dark.png` and `unityeditorai-banner-light.png` were created with the built-in OpenAI Imagegen tool on 2026-10-23 and approved by the maintainer for this README.
- The maintainer supplied the penguin character reference from their profile banner. The dark banner uses that actual reference as image input; the light variant was edited from the dark banner to preserve the same character, gesture, composition and objects.
- Concept: the penguin turns a speech bubble into a coral cube, lavender sphere and mint cylinder. The light version uses ivory, dark aubergine text and purple outlines; it is not a color negative.
- These are AI-generated illustrations, not product screenshots or official Unity assets. No Unity logo is used and no partnership is implied.
- The README selects the matching asset through native `picture`/`source` theme queries, with the light image as fallback. Both variants were checked locally at 1280, 390 and 320 px; no separate mobile crop was needed.
- No new project-wide or asset license is granted. The project's existing all-rights-reserved notice and university/industry caveats remain unchanged. Image generation does not independently establish reference-character rights.
